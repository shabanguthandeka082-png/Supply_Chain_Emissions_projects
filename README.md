# Supply_Chain_Emissions_projects
      excel dashboard analysing supply chain emission across industries
## Project Overview
This project analyzes supply chain emission factors across industries using Excel dashboards and pivot tables.

## Objectives
- Identify industries with the highest emissions
- Analyze supply chain environmental impact
- Build interactive dashboards for reporting

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Slicers
- Dashboard Design

## Key Insights
- Cement manufacturing showed high emission factors
- Livestock industries contributed significantly to emissions
- Transportation sectors displayed moderate emission levels
